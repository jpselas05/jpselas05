## ⚙️ Projetos Principais

### ⚖️ [Jurivo](https://jurivo-gamma.vercel.app)
O escritório de advocacia inteiro num só lugar: tarefas da equipe, controle de pagamentos e o andamento dos processos atualizado automaticamente a partir do CNJ, sem precisar consultar tribunal por tribunal.

Arquitetura monolítica modular sobre PostgreSQL, com rotinas agendadas em Deno para o monitoramento processual.

`TypeScript` `PostgreSQL` `Deno`

### 🚀 [Mollire](https://mollire.vercel.app)
Conecte seu repositório do GitHub e coloque seu frontend no ar em poucos cliques, com subdomínio próprio e acompanhamento do build em tempo real.

Suporte a SPA e SSR. Clone via GitHub API, build e execução isolados em containers Docker, logs de build via SSE e roteamento dinâmico de subdomínios com `map` do Nginx como reverse proxy.

`Docker Compose` `Nginx` `SSE` `GitHub API`
